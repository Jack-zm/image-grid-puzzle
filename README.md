# 🖼️ 图片网格打乱加密 / 一键还原

纯前端（单 HTML 文件，无任何依赖）的图片"网格打乱 + 负片"加密与还原工具。

## 功能

- 上传图片，一键将图片切成 **N×N 网格**（行列数以变量 `gridRows / gridCols` 存储，默认 **8×8**，界面提供输入框可随时修改）
- 对每个网格执行**负片取反**（255 − 像素值）
- 按**随机种子**生成的置换顺序**打乱**网格
- 一键**还原**：同一页面直接还原，或把处理后的 PNG **重新上传**再还原，均可得到原始图片
- 种子记录与载入：跨会话/跨设备还原只需粘贴种子
- 像素级一致性校验：还原后自动与原图像素比对
- 处理结果 / 还原结果均可下载 PNG

## 使用步骤

1. 上传**原始图片**（拖拽或点击）
2. 调整网格行列（默认 8×8），点击「🔀 加密并打乱」
3. 查看处理结果，记下**种子**（或点复制）
4. 还原方式二选一：
   - 直接点击「🔄 还原原图」（使用页面内的处理结果）
   - 下载处理结果 PNG，重新上传到「上传处理后的图片」入口，再点击还原（跨会话时先粘贴种子）
5. 下载还原结果，与原始图片像素完全一致 ✅

## 工作原理

- **负片取反是自逆运算**：对同一像素取反两次即恢复原值
- **打乱由种子决定**：还原时计算置换的**逆置换**，把小格放回原位
- 两者组合即可实现"加密 → 无损还原"

注意：还原必须使用与加密时相同的**网格行列**与**种子**；请使用 PNG 等**无损格式**保存，保证像素一致。

## 技术说明

- 纯浏览器 Canvas API 实现，图片全程本地处理，不上传服务器
- 核心变换函数（`shuffledPermutation` / `invertPermutation` / `applyTransform`）为纯函数，已通过往返还原测试（`test-core.js`）
- 超大图片自动缩放到最长边 4096px，还原仍像素级一致
