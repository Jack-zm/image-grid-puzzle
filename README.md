# 🖼️ 图片网格打乱加密 / 一键还原

纯前端（单 HTML 文件，无任何依赖）的图片"网格打乱 + 负片"加密与还原工具。**页面无后端，所有功能在浏览器本地 JS 实现，仅需打开 HTML 页面即可使用。**

## 功能

- 上传图片，一键将图片切成 **N×N 网格**（行列数以变量 `gridRows / gridCols` 存储，默认 **8×8**，界面提供输入框可随时修改）
- 对每个网格执行**负片取反**（255 − 像素值）
- **每次处理使用随机种子**打乱网格，同一张图多次处理结果各不相同
- **种子包含分割行列**（格式 `行x列-密钥`，如 `8x8-1234567890`）：还原时只需粘贴生成页面提供的种子，**自动识别行列，无需再输入行列值**
- 一键**无损还原**（两种方式，像素级一致）：
  - 同一页面直接点击「🔄 还原原图」
  - 将打乱的 PNG **重新上传**到「上传处理后的图片」入口，**粘贴生成页面的种子**后还原
- 种子一键复制；种子记忆在本浏览器（localStorage），刷新后自动载入，也可「清除记忆」
- 像素级一致性校验：还原后自动与原图像素比对，种子错误会明确提示
- 处理结果 / 还原结果均可下载 PNG

## 使用步骤

1. 打开 `index.html`（或在线预览），上传**原始图片**（拖拽或点击）
2. 调整网格行列（默认 8×8），点击「🔀 加密并打乱」
3. 查看处理结果，页面会显示本次的**种子**（如 `8x8-1234567890`，含分割行列，可复制）——**该种子是唯一还原密钥**
4. 还原方式二选一：
   - 直接点击「🔄 还原原图」（使用页面内的处理结果）
   - 下载处理结果 PNG，重新上传到「上传处理后的图片」入口，**粘贴生成页面的种子**（无需再设网格），再点击还原
5. 下载还原结果，与原始图片像素完全一致 ✅（种子错误时会提示不一致）

## 工作原理

- **负片取反是自逆运算**：对同一像素取反两次即恢复原值
- **打乱由随机种子决定**：每次加密生成随机 32 位密钥，密钥生成确定性置换；还原时计算置换的**逆置换**，把小格放回原位
- **种子 = 行x列-密钥**：种子本身包含分割行列，解析种子即可同时获得网格与打乱顺序，**仅凭生成页面的种子即可无损还原，无需输入行列**

注意：还原必须使用生成页面提供的种子（种子已含行列）；请使用 PNG 等**无损格式**保存，保证像素一致。

## 技术说明

- **零依赖、零后端**：单个 HTML 文件内嵌全部 CSS/JS，不加载任何外部资源，图片全程在浏览器本地处理，不会上传到任何服务器
- 核心纯函数（`shuffledPermutation` / `invertPermutation` / `applyTransform` / `buildSeedStr` / `parseSeedStr`）已通过往返还原测试（`test-core.js`，含仅凭种子还原、随机种子可复现、种子编解码、旧版种子兼容等 21 项用例）
- 超大图片自动缩放到最长边 4096px，还原仍像素级一致
