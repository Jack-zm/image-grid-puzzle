# 🖼️ 图片网格处理 · 同种子可逆

纯前端（单 HTML 文件，无任何依赖）的图片"网格打乱 + 负片"处理工具。**页面无后端，所有功能在浏览器本地 JS 实现，仅需打开 HTML 页面即可使用。**

## 功能

- **多种图片来源**：本地文件（点击/拖拽上传）、**粘贴图片链接**（输入框 + 「加载链接」）、**网页右键复制图片 / 截图后直接 Ctrl+V 粘贴**、剪贴板图片
- 上传图片，点击「⚙️ 处理」：切成 **N×N 网格**（行列数以变量 `gridRows / gridCols` 存储，默认 **8×8**，界面提供输入框）→ **负片取反** → 按种子**打乱**
- **处理是自逆运算**：同一图片用**相同种子再处理一次即回到原图**（打乱 ↔ 还原，像素级无损）
- **未输入种子时**：按当前行列值自动生成随机种子处理；网格未变时再次点击沿用上次种子（即可逆）
- **输入种子时**：按种子处理（种子格式 `行x列-密钥`，如 `8x8-1234567890`，**包含分割行列**，优先于网格输入）
- 种子一键复制；种子记忆在本浏览器（localStorage），刷新后自动载入，也可「清除记忆」
- 处理结果可下载 PNG（无损）

## 使用步骤

1. 打开 `index.html`（或在线预览），获取图片（任选其一）：
   - 点击/拖拽上传**本地文件**
   - 在其他网页**右键复制图片**、或**截图**后，回到本页 **Ctrl+V 粘贴**
   - 复制图片**链接**粘贴到输入框 → 点「加载链接」（或直接 Ctrl+V 粘贴链接，页面自动识别）
2. 可选：粘贴种子（不填则按网格行列自动生成随机种子）；可调整网格行列（默认 8×8）
3. 点击「⚙️ 处理」→ 图片被打乱+取反，页面显示本次使用的**种子**
4. 再次点击「处理」（种子不变）→ 图片**回到原图** ✅（页面自动比对并提示"已还原"）
5. 也可下载处理结果 PNG 分享；对方上传该图、粘贴种子、点击处理即可还原

## 工作原理

- **负片取反是自逆运算**：对同一像素取反两次即恢复原值
- **打乱使用自逆置换**：种子密钥生成若干"两两互换对"（σ(σ(i)) = i），同一映射作用两次等于恒等
- **种子 = 行x列-密钥**：种子包含分割行列与密钥，解析种子即可同时获得网格与打乱方式
- 三者结合 ⇒ **处理是自逆运算**：同一图片用同一种子处理两次必然无损回到原图

注意：请使用 PNG 等**无损格式**保存，保证像素一致。

## 技术说明

- **零依赖、零后端**：单个 HTML 文件内嵌全部 CSS/JS，不加载任何外部资源，图片全程在浏览器本地处理，不会上传到任何服务器
- **链接图片说明**：通过链接加载的图片需要其站点允许跨域（CORS），否则浏览器无法读取像素，页面会提示改用下载/粘贴方式；本地文件和剪贴板粘贴的图片不受此限制
- 核心纯函数（`shuffledPermutation` / `selfInversePermutation` / `invertPermutation` / `applyTransform` / `buildSeedStr` / `parseSeedStr`）已通过往返测试（共享套件 `test-suite.js`，网页版 `test-core.js` 与小程序版 `test-core-mp.js` 均 31 项全过）
- 超大图片自动缩放到最长边 4096px，可逆仍像素级一致
