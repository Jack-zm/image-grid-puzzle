上传图片 → 切成 N×N 网格 → 负片取反 → 随机种子打乱。种子包含分割行列（如 8x8-xxxx），上传处理后的图片（或直接在同一页面）粘贴生成页面的种子即可无损还原。全部功能在浏览器本地完成，无后端、无需联网。

2网格设置

行列数存于 JS 变量 gridRows / gridCols，可自由修改（默认 8×8）。生成的种子会包含行列（如 8x8-xxxx），还原时只需粘贴种子，无需再设置网格。

4种子（还原密钥）

每次加密使用随机种子打乱。种子格式为「行x列-密钥」（如 8x8-1234567890），已包含分割行列：还原时只需粘贴生成页面的种子，无需再输入行列值；负片取反是自逆运算（取反两次即复原）。

5下载

请以 PNG 无损格式导出/导入，保证像素一致、可完美还原。

打乱映射（每格数字 = 该位置取自原图的第几格，从左到右、从上到下从 0 编号）

完成加密后在此显示打乱顺序
工作原理：① 将图片按「行×列」切成小格（行列存于变量 gridRows/gridCols，可在左侧修改）；② 对每个小格做负片取反（255 − 像素值）；③ 按随机种子生成的置换顺序打乱小格。种子格式为「行x列-密钥」，已包含分割行列。 还原时：把当前图片重新切格 → 按逆置换把小格放回原位 → 再取反一次（抵消负片），即得原图。同一页面直接还原，或下载 PNG 后重新上传到「处理后的图片」入口，把生成页面的种子粘贴到种子框——自动识别行列，无需手动设置网格，即可无损还原。
注意：还原必须使用生成页面提供的种子（种子已含行列）；请使用 PNG 等无损格式。所有功能均在浏览器本地运行（纯前端 JS + Canvas），页面无后端、不加载任何外部资源，图片不会上传到任何服务器。
